# Demo Reacti asset

`friend_moment.png` is the canned "friend's moment" the practice demo opens
(Feature 2). It is currently a **placeholder** (a copy of an onboarding image).

**To swap in the real clip:** drop a short (~3–6s), portrait, small (<~2 MB)
image or video here and point `DemoReactiScreen.friendMediaAsset` at it. A cute
CC0/royalty-free kitten clip works well — use a licensed source (Pexels,
Pixabay) since this ships in the App Store build. No code change beyond the
asset path (and, for a video, swapping `Image.asset` for a `video_player`).
